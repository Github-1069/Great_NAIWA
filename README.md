# 合成大奶娃 · PWA 离线单机版

本目录是可独立部署的修改版，来源为 https://github.com/yhsome/BigNaiWa ，基于提交 `1c43d40`。原始下载目录 `../BigNaiWa` 保持不变。上游说明保存在 `UPSTREAM-README.md`，其中排行榜等描述属于原版，不适用于本版本。沿用上游“仅供学习娱乐使用”的说明。

## 已修改

- 删除在线排行榜、昵称、成绩上传、赞助入口及相应脚本和样式。
- 全部游戏资源随目录提供，不使用 CDN、云端 API 或远程字体。
- 添加应用清单、桌面图标和 Service Worker，首次联网缓存完成后可断网启动。
- “安装 / 离线”按钮可查看准备状态、安装步骤、重试失败下载。
- 离线就绪以实际缓存检查为准，不以“网络断开”或“已添加图标”冒充完成。
- 新版本整批下载成功后等待所有旧游戏窗口关闭，再启用，避免打断当前局。
- 切到后台、打开安装说明时暂停游戏推进。
- 最高分、静音设置保存在当前浏览器本地；没有账户同步，也不保存未结束的一局。

## 手机使用：首次联网，之后离线

1. 把本目录作为静态网站部署到 **HTTPS** 地址。所有文件的相对路径必须保持不变，`sw.js` 与 `index.html` 同级。可部署在网站根目录或 `/项目名/` 子目录。
2. 用手机浏览器打开你的部署网址（不是原作者的网址）。
3. 等到“已准备好，可以离线游玩”提示；也可点“安装 / 离线”检查。
4. 安卓：浏览器菜单“安装应用 / 添加到主屏幕”，或页面提供的“安装到桌面”按钮。iPhone：Safari 的“分享 → 添加到主屏幕”，如出现“作为网页 App 打开”，请开启。
5. 从桌面图标打开一次，确认仍显示离线就绪，然后关闭，打开飞行模式，再从桌面图标打开测试。

首次保存或版本更新需要联网；完整缓存后的核心游戏无需联网。清理网站数据或系统回收存储后需重新准备，最高分也可能丢失。浏览器与桌面应用之间的存储共享因平台而异，请在最终使用的桌面应用中确认离线状态。

### GitHub Pages 部署示例

创建你自己的仓库，将本目录中的内容放到仓库根目录（`index.html` 直接在根目录），在仓库 Settings → Pages 中选择从分支部署，选择相应分支及根目录。发布完成后访问 GitHub 提供的 HTTPS 地址。也可使用其他支持静态文件和 HTTPS 的服务。

本次只交付本地文件，**尚未发布网站**。不需要后端、数据库、npm 构建或排行榜账号。

## 电脑本地预览

在本目录运行（已安装 Node.js）：

```sh
node serve.cjs
```

浏览器打开 http://localhost:8080 。按 Ctrl+C 停止。

双击 `index.html` 可以玩本地游戏，但 `file://` 不能注册这个 PWA。手机访问电脑的普通 `http://局域网IP:端口` 同样不能正常安装离线缓存；手机正式使用请用 HTTPS。电脑预览服务器只绑定本机。

## 更新规则

修改任何运行资源时，递增 `sw.js` 的 `VERSION`（如 `v1` → `v2`），并将整个版本一起部署。新增资源要同步加入 `ASSETS` 及 `pwa.js` 的重试清单。

新版本缓存失败不会替换旧版本。成功后会提示关闭所有游戏窗口再打开；不会自动刷新当前游戏。缓存按部署路径隔离，不会清理同一域名下其他应用的缓存。离线时保持现有版本，联网后再检测更新。

## 验证

```sh
node physics.test.js
node gameplay.test.js
node pwa.test.cjs
```

前两个检查不需要依赖。`pwa.test.cjs` 需要本机可解析的 `playwright` 包及 Chromium；可通过 `PWA_BROWSER` 指定 Chrome/Edge 可执行文件。测试会启动临时本机服务并创建临时浏览器数据目录，验证完整缓存、断网重新启动、资源缺失恢复、更新等待、下载失败和手机尺寸布局。不会访问线上排行榜。

运行所需文件：`index.html`、`style.css`、`game.js`、`pwa.css`、`pwa.js`、`sw.js`、`manifest.webmanifest`、`icons/`、`assets/`。说明、测试和预览脚本不参与离线缓存。
